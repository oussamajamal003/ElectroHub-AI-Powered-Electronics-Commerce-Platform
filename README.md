# ElectroHub-AI-Powered-Electronics-Commerce-Platform
ElectroHub — A full-stack electronics e-commerce platform built with React, TypeScript, Node.js, Express, Prisma, Supabase PostgreSQL, FastAPI AI, Stripe, Brevo, Socket.IO, Cloudinary, Leaflet, Docker, and GitHub Actions, deployed on DigitalOcean with Nginx and SSL.
