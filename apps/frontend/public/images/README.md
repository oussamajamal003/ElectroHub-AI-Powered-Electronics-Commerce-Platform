# Product catalog media

The original Task 02.5 SVG illustrations remain available as local alternate-view art. Task 03.1 adds locally stored, AI-generated, unbranded JPEG studio photographs under `catalog/` for category tiles and representative seed Product imagery. They depict product categories rather than exact manufacturer models; names and visible specifications remain the factual seed data. The `catalog/variety/` directory contains three alternate category views for each of the eight product categories and three separate Apple-style phone views to keep phone imagery coherent with the seed brand.

All media is served from the application with no runtime external image requests. The seed deterministically rotates each Product through model or category pools, including separate iPhone 15/16, iPad 10/Air, and MacBook Air 13/15 views; each Product receives two distinct primary and alternate ProductImage records. These are representative device views, not exact model photography. Brand logos remain null. New JPEGs are resized to at most 1200px and compressed at quality 84. The current pool is still too small to satisfy a two-Product maximum reuse across all 128 configurations; the seed audit records the remaining duplicate counts.
