## Inspect, retry and reconcile

Storage requests default to 10 seconds. Set `PRODUCT_MEDIA_STORAGE_TIMEOUT_MS` only within 100–30000 ms when measured network latency requires it. DEV QA used 30000 after a real-photo upload/read-back took 18.5 seconds and requests exceeded the default. Timeouts remain safe 503s; they never publish an unverified reference. Media SQL transactions use the existing cart/wishlist budget (10-second acquisition, 30-second execution), with at most eight gallery rows and all decoding/Storage work outside transactions.

* `node --import tsx scripts/product-media-ops.ts status` reports active version, each worker's READY/PROCESSING/STOPPING/STOPPED/FAILED/STALE state, heartbeat age and event counters, plus pending/retry/permanent-failure counts and oldest pending age. No heartbeat row is reported as UNAVAILABLE; heartbeats older than 60 seconds are STALE. Queue health remains separate from process health.
* `node --import tsx scripts/product-media-ops.ts reconcile` inventories bounded Storage paths and DB references, reports missing objects/retained history/orphan candidates, and performs **no deletion**. It fails if inventories exceed their safety bounds. A listing/report is not a deletion authorization, and concurrent changes require a new inventory before any future cleanup.
* `PRODUCT_MEDIA_OPERATOR_TARGET=<exact target identity>` plus `node --import tsx scripts/product-media-ops.ts retry <event UUID>` requeues only current-source failed/retry-wait work. It locks and rechecks the event; it refuses PROD. The equivalent admin retry endpoint checks live ADMIN and product/image ownership.
* Worker: from `apps/ai-service`, run `venv\Scripts\python.exe -m app.media_sync --once` for a bounded check, or `python -m app.media_sync` under a supervisor. Startup remains STARTING until its DB role privileges, active model artifact, and Storage source configuration pass. SIGINT/SIGTERM stops new claims, lets the current bounded operation finish, flushes STOPPED, and closes the encoder; crash recovery relies on lease expiry. Heartbeat rows are pruned after seven days. Never launch a global worker against a shared queue during a narrowly scoped smoke test.

Inspect safe structured events `ai.media_event_completed`, `ai.media_event_failed`, `ai.media_event_lease_lost` and `ai.media_index_coverage`. Check pending age, permanent failures, descriptor mismatch and digest mismatch independently from API health. A published image with pending/failed indexing remains a successful catalog publication.

Storage outage: new uploads return a safe retryable error; no new ProductImage/event commits before verified upload. Preserve local preview and mutation UUID. After restoration, retry the same intent. Objects from failed/uncertain commits stay retained for reconciliation.

AI outage: keep serving catalog images and ordinary commerce. Stop/restart the worker with its exact artifact; expired leases can be reclaimed, exhausted work becomes visible as a permanent failure. Do not mark events completed manually or switch model versions to clear failures. A changed model requires normal approved registration/activation and source-current validation.

Missing source/digest mismatch: inspect the exact canonical object and revision; do not overwrite its immutable path. Repair by a new authorized replacement/revision. Descriptor mismatch: verify manifest/artifact SHA and preprocessing, then restart the compatible worker; never substitute a same-dimensional encoder. Hidden/retired images remain excluded directly in the reader even while workers are stopped.
