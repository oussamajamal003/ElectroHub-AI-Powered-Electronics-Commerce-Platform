# Customer Screenshots — Figma Make Visual References

## Purpose

This folder contains screenshots captured from the **ElectroHub Figma Make** design workspace for the **Customer Experience**.

The screenshots are visual references for implementation, design handoff, and visual QA. They document the customer-facing shopping experience across discovery, product browsing, cart, checkout, orders, account, and responsive layouts.

**Figma Design remains the authoritative visual source of truth.** These screenshots do not replace the live Figma Design file.


The set visibly contains spaces, underscores, hyphens, mixed capitalization, concatenated names, and generic timestamp-based capture names.

**These are examples of the observed Figma Make output, not a naming convention to enforce. Preserve every screenshot filename exactly as generated. Do not rename or normalize screenshots into `<Screen> — <State>.png` or `<Screen> — <Viewport>.png`.**


### Preserve Figma Make Default Filenames

Screenshots captured from Figma Make should keep the **default screenshot filename generated by Figma Make**.

Do **not** manually rename screenshots to a custom convention such as:

```text
Customer Home — Desktop.png
Customer Home — Tablet.png
Customer Home — Mobile.png
Products — Desktop.png
Product Details — Desktop.png
Cart — Desktop.png
Checkout — Desktop.png
```

Do not require a:

```text
<Screen> — Desktop.png
<Screen> — Tablet.png
<Screen> — Mobile.png
```

naming pattern.

The filename does not need to encode the screen, state, or viewport.

Context should come from:

- This README
- The `customer/` folder
- The `screenshots/` directory
- The visible content of the screenshot
- The corresponding Figma Design frame

Do not rename, normalize, or invent filenames unless an explicit repository requirement is introduced later.
